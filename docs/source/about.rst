About BESSER
============

BESSER stands for *BEtter Smart Software fastER*. It is an
`FNR-funded PEARL project <https://www.fnr.lu/funding-instruments/pearl/>`_
hosted at the `Luxembourg Institute of Science and Technology
<https://www.list.lu/>`_ in collaboration with the University of Luxembourg.

The platform provides a :doc:`model language <buml_language>`, a
:doc:`browser editor <web_editor>`, and :doc:`code generators <generators>`.
The experimental :doc:`Spec-Driven Agent <spec_driven_agent/index>` adds
AI customisation and validation to application generation. It uses an
existing scaffold when one fits the requested stack.
