Start here
==========

You can use BESSER through the browser or as a Python library. Both work with
B-UML models: descriptions of your system that code generators turn into source
files.

.. list-table::
   :header-rows: 1
   :widths: 30 40 30

   * - I want to…
     - Start with
     - What I need
   * - Try what I saw in a demo
     - :doc:`browser`
     - A browser
   * - Generate code from Python
     - :doc:`first-model`
     - Python 3.11 or 3.12
   * - Describe an app and generate it with AI
     - :doc:`../guides/build-with-ai`
     - A browser and an available model provider
   * - Run the platform on my own machine
     - :doc:`../operations/index`
     - Git and Docker, or a source development setup

You do not need an AI provider to draw models or use the deterministic
generators. AI assistant and Spec-Driven Agent availability depend on the
deployment and its configured providers.
